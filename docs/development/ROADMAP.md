# Development Roadmap

This document outlines the high-level plan to reach the goals defined in `docs/project.md`.

## Phase 1: Client Expansion
Expand the reach of the Cronus server by implementing additional clients.

- **Task 006**: Implement CLI Client
    - Enable terminal-based interaction.
    - Validate API stability with a second client type.
- **Task 007**: Implement VS Code Extension
    - Bring AI assistance directly into the IDE.
    - Re-use Web Client components.

## Phase 2: Agent Capabilities & Configuration
Deepen the intelligence and flexibility of the system.

- **Task 009**: Advanced Configuration System
    - Prerequisite for specialized agents to allow custom prompts/tools.
- **Task 008**: Implement Specialized Agents
    - Build Formatter, Debugger, Tester, and Optimizer agents on top of the generic "Coder" infrastructure.

## Phase 3: Integrated Development Workflow
Realize the goal of a self-managing development process.

- **Task 010**: Built-in Development Process Integration
    - Implement state tracking for tasks and code.
    - Integrate with the file-based task system.
