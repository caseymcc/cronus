# Task: Implement VS Code Extension

## Description
Create a Visual Studio Code extension that integrates the Cronus agent directly into the editor.

## Requirements
- TypeScript extension in `clients/vscode`
- Reuse UI components from `clients/web` (webview) where possible
- Connect to Cronus Server REST API
- Features:
    - Chat sidebar
    - Code suggestions/inline completion (optional)
    - Context menu integration ("Ask Cronus")
    - Workspace context awareness

## Dependencies
- Cronus Server running
- Web client components (for reuse)
