# Task: Advanced Configuration System

## Description
Implement a robust configuration system to allow users to customize providers, models, and tools.

## Requirements
- Load configuration from files (e.g., JSON/YAML)
- support for:
    - Defining LLM Providers (OpenAI, Gemini, etc.)
    - Custom Model definitions with parameters
    - Custom System Prompts per agent
    - Custom Tools definitions
    - Language-specific formatting rules
- Hot-reloading of config (optional but good)

## Dependencies
- Cronus Server Config Module
