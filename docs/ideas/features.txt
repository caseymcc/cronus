Planned Core Features (Dual-Mode Architecture)

 1 Operational Mode System ⭐ PRIORITY                                                                                                               
    • Automatic mode detection (single-agent vs multi-agent)                                                                                        
    • Single-Agent Mode:                                                                                                                            
       - One AI agent per repository                                                                                                                
       - Configuration in .cronus/ at repository root                                                                                               
       - Direct file modification                                                                                                                   
       - Lock mechanism to prevent concurrent instances                                                                                             
    • Multi-Agent Mode:                                                                                                                             
       - Multiple agents with isolated workspaces                                                                                                   
       - Each agent in agents/<agent-id>/ with own .cronus/                                                                                         
       - Parallel agent execution                                                                                                                   
       - Agent comparison and metrics                                                                                                               
    • Mode initialization and directory structure setup                                                                                             

 2 Configuration Management ⭐ PRIORITY                                                                                                              
    • JSON-based configuration files                                                                                                                
    • Environment variable substitution (${VAR})                                                                                                    
    • Configuration validation with JSON schemas                                                                                                    
    • Hot reload support                                                                                                                            
    • Configuration inheritance (multi-agent: global → per-agent)                                                                                   
    • CLI commands: config show/edit/set/validate/reset                                                                                             

 3 State Persistence ⭐ PRIORITY                                                                                                                     
    • Agent state tracking (active/idle/error)                                                                                                      
    • Session management and recovery                                                                                                               
    • Task state persistence (todo/in-progress/done)                                                                                                
    • Conversation history (JSON Lines format)

    • Automatic backups (last N versions)                                                                                                           
    • State recovery from backups                                                                                                                   

 4 Single-Agent Mode Implementation

Implementation Notes

• Mode detection priority:
  1. Check for .cronus/ and parse config
  2. Check for .git/ or other VCS markers → single-agent
  3. Check if directory is empty → multi-agent
  4. Allow explicit override via --mode flag

• Rate file importance based on:
  - Called functions
  - Call tree analysis
  - Dependency graph
  - Recent modification frequency

• Context optimization:
  - Summarize functions when context is limited
  - Cache summaries for reuse
  - Send full code when context allows, summaries when constrained
  - Use loreforge embeddings for intelligent context selection

• Multi-agent workspace structure:
  workspace/
  ├── .cronus/              # Global config and shared resources
  └── agents/
      ├── agent-1/
      │   ├── .cronus/      # Agent-specific config
      │   └── [repo files]  # Agent's repository
      └── agent-2/
          ├── .cronus/
          └── [repo files]
